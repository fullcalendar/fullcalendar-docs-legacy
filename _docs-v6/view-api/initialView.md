---
title: initialView
---

The initial view when the calendar loads.

<div class='spec' markdown='1'>
String
</div>

A name of any of the available views, such as `'dayGridWeek'`, `'timeGridDay'`, `'listWeek'`.

If omitted, the calendar shows the default view of the first plugin in [plugins](plugin-index) that provides one: `'dayGridMonth'` for DayGrid, `'timeGridWeek'` for TimeGrid, `'multiMonthYear'` for MultiMonth, `'timelineDay'` for Timeline, `'resourceTimelineDay'` for Resource Timeline, `'resourceTimeGridDay'` for Resource TimeGrid, and `'resourceDayGridDay'` for Resource DayGrid.
